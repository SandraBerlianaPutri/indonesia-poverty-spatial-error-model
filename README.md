# Unraveling the Roots of Poverty in Indonesia: Spatial Error Model Analysis

## About
This project investigates factors associated with poverty across Indonesia in 2024 using spatial regression. The analysis focuses on the Spatial Error Model (SEM), which accounts for spatial dependence in regression errors, to examine poverty beyond the assumptions of conventional regression.

The project was prepared for **Jambore Statistika XIV**, organized by HIMASTA, Mulawarman University, in December 2024. Participation status: **National Participant**.

## Dataset
- **Geographic coverage:** Indonesia.
- **Reference year:** 2024, as stated in the project title.
- **Unit of analysis:** Regional observations, according to the source dataset.
- **Response variable:** Poverty measure used in the analysis.
- **Explanatory variables:** Regional socioeconomic indicators included in the original dataset.
- **Spatial information:** Regional data and spatial relationships used to construct the spatial weights matrix.

## Methods
- **Exploratory Data Analysis:** Examined the distribution and regional variation of poverty-related indicators.
- **Regression Analysis:** Established a regression framework for investigating factors associated with poverty.
- **Spatial Dependence Assessment:** Examined spatial relationships to motivate spatial regression.
- **Spatial Error Model (SEM):** Modeled spatial dependence in regression errors.
- **Model Evaluation:** Assessed model results using the criteria and diagnostic tests reported in the original analysis.
